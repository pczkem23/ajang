# 아장 · 아기장터

> 우리 아이가 졸업한 물건, 누군가의 첫 시작이 되도록.

임신부부터 만 6세 자녀를 둔 부모를 위한 **육아용품 전문 중고거래 앱**입니다.
일반 중고거래 앱과의 차별점은 세 가지입니다.

1. **아이 월령에 맞춰 상품을 발견한다** — 아이 생년월일(또는 출산 예정일)을 등록하면 지금 월령과 다음 단계에 맞는 물건을 먼저 보여줍니다.
2. **사용 이력과 상태를 비교한다** — S/A/B/C 상태 등급, 사용 개월 수, 신품가 대비 절약률을 표준화해서 표시합니다.
3. **누구나 쉽게 판매글을 쓴다** — 설명 템플릿으로 시작하고, 이후 AI 사진 인식 자동 등록으로 확장합니다.

## 기술 스택

| 영역 | 선택 | 이유 |
|---|---|---|
| 앱 | Expo (React Native) + Expo Router + TypeScript | 하나의 코드로 iOS·안드로이드·웹 동시 출시. 1,000만 원 이하 예산에 맞음 |
| 백엔드 | Supabase (Postgres, Auth, Storage, Realtime) | 서버 직접 운영 없이 DB·로그인·사진 저장·실시간 채팅 해결 |
| 빌드/배포 | EAS Build / EAS Submit | Mac 없이도 앱스토어·플레이스토어 빌드 |

## 실행

```bash
npm install
cp .env.example .env   # Supabase 접속 정보 (공개 키)
npm start        # Expo Go 앱으로 QR 스캔
npm run web      # 브라우저에서 확인
npx tsc --noEmit # 타입 체크
```

## 폴더 구조

```
app/                 화면(라우트)
  (tabs)/            하단 탭 5개: 홈 · 카테고리 · 판매하기 · 채팅 · 마이
  listing/[id].tsx   상품 상세
src/
  data/catalog.ts    카테고리 8종, 월령 8구간, 상태 등급 정의
  api/               Supabase 조회·등록 (listings, profile)
  lib/supabase.ts    Supabase 클라이언트
  lib/auth.tsx       로그인 세션·내 프로필 상태
  lib/age.ts         월령 계산·추천 로직
  components/        공용 UI
supabase/schema.sql  DB 스키마 + RLS 보안 정책
supabase/migrations/ 이후 변경분 (002: 우리 집 육아용품)
```

## 안전 원칙

카시트·유모차·유아침대 같은 안전 관련 제품은 상태 등급만으로 안전성을 보증하지 않습니다.
제조일·모델명·리콜 여부 입력을 유도하고, 상세 화면에 확인 안내를 항상 표시합니다.
